# Minicraft

Jeu sandbox 2D procédural jouable dans le navigateur.

## Jouer

Ouvrir [Minicraft](https://mateo-llr.github.io/Minicraft/).

Pour jouer localement, ouvrir `index.html` dans un navigateur. Garder le dossier `assets` à côté du fichier HTML : il contient les textures et les données d'animation.
