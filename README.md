# Minicraft

Jeu sandbox 2D procédural jouable dans le navigateur.

## Jouer

Ouvrir [Minicraft](https://mateo-llr.github.io/Minicraft/) après activation de GitHub Pages.

Pour jouer localement, ouvrir `Minecraft 2D.html` dans un navigateur. Garder le dossier `assets` à côté du fichier HTML : il contient les textures et les données d'animation.
